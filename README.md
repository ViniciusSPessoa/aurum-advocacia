AURUM — ADVOCACIA & CONSULTORIA
Projeto fictício de portfólio

1. EXECUÇÃO
Abra index.html no navegador. Não há dependências externas.
Mantenha a pasta images original junto aos arquivos do projeto.

2. ATUALIZAÇÃO DO JAVASCRIPT
Substitua app.js pelo novo arquivo. Não altere index.html ou style.css.
O HTML já carrega app.js com defer.

3. ORGANIZAÇÃO DE APP.JS
01. Configurações gerais
02. Menu de navegação
03. Animações de entrada
04. Áreas de atuação e troca de imagens
05. Contato pelo WhatsApp
06. Efeito parallax
07. Inicialização da página

4. CONFIGURAÇÕES
Para ativar o WhatsApp, preencha CONFIG.whatsappNumber em app.js
com o número autorizado, incluindo código do país e DDD, apenas dígitos.
Enquanto estiver vazio, o botão apresenta um aviso demonstrativo.
Os parâmetros originais de animação estão reunidos em CONFIG.
A ordem dos painéis de atuação deve acompanhar a ordem das imagens.

5. PUBLICAÇÃO
Configure o sitemap após definir o domínio.
As imagens WebP são recortes de referência visual gerada e aprovada,
não fotografias reais, conforme a documentação original.

6. VALIDAÇÃO
Sintaxe do JavaScript verificada com Node.js.
Testes visuais e de interação em navegador ainda pendentes.
HTML e CSS originais não foram modificados.
